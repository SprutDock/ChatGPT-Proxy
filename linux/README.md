# ChatGPT Proxy для Linux

1. Распакуйте архив и один раз запустите `bash install.sh`.
2. Откройте меню приложений и запускайте **ChatGPT Proxy**. При желании добавьте этот пункт в избранное или Dock.

При первом запуске launcher сам создаёт недостающие proxy-строки в `~/.codex/.env`, сохраняя остальные настройки и уже заданные значения `.env`. `config.toml` launcher не создаёт и не меняет. Затем он закрывает открытый процесс ChatGPT и запускает `chatgpt` с proxy-переменными и `--proxy-server`. Пункт меню использует иконку ChatGPT. Системный прокси не меняется.

Адрес по умолчанию находится в `proxy-url.txt` в архиве.

Linux-клиент ChatGPT сейчас доступен как preview для Ubuntu 24.04/26.04, Debian 13, Fedora 43/44 и актуального Arch Linux. Другие дистрибутивы официально не поддерживаются. Для корпоративного развёртывания проверьте launcher на каждой целевой сборке и задайте `.env` через MDM или систему управления конфигурацией.
