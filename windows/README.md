# ChatGPT Proxy для Windows

1. Распакуйте архив в постоянную папку и один раз запустите `Create-ChatGPT-Proxy-Shortcut.vbs`. Он создаст на рабочем столе ярлык с иконкой ChatGPT.
2. Запускайте ChatGPT через новый ярлык. При первом запуске launcher сам создаст недостающие proxy-настройки в `%USERPROFILE%\.codex\.env`.

Launcher сохраняет уже заданные значения `.env`, не меняет `config.toml`, закрывает открытый ChatGPT и запускает `OpenAI.Codex` в контексте MSIX-пакета с proxy-переменными и `--proxy-server`. Системный прокси не меняется. Обычный ярлык ChatGPT не передаёт эти параметры. Если запуск завершится ошибкой, окно консоли останется открытым.

Адрес по умолчанию задаётся в `proxy-url.txt` в архиве. Если `.env` уже содержит proxy, launcher не заменяет его.

Компаниям следует подписать PowerShell-скрипт сертификатом организации и распространить launcher через управляемый пакет. Не включайте обход корпоративной PowerShell execution policy. Если Windows Script Host заблокирован, создайте ярлык на `Start-ChatGPT-Proxy.cmd` вручную и укажите `chatgpt.ico` в его свойствах.

Если PowerShell сообщает, что выполнение сценариев отключено, проверьте `Get-ExecutionPolicy -List`. При эффективной политике `Restricted` Windows блокирует `.ps1` даже с подписью. Администратор должен разрешить подписанные сценарии, например через `AllSigned`, и развернуть доверие к сертификату компании. Если `MachinePolicy` или `UserPolicy` заданы через GPO, их может изменить только администратор этой политики.

Windows-версию launcher нужно проверить на пилотном компьютере с установленным ChatGPT Desktop: запуск в контексте MSIX-пакета и proxy-флаг не проверены на Windows в этой сборочной среде.
